# YouTube Downloader Web Version

A single page website to download youtube videos built with [yt-dlp](https://github.com/yt-dlp/yt-dlp) and Flask.  
List all available video/audio formats of a YouTube video and download in your chosen format.

Created by: [@b1ack-devi1](https://github.com/b1ack-devi1)

##  Installation
- Clone the repository:	
   ```bash
   git clone https://github.com/b1ack-devi1/YT-Downloader.git
   cd YT-Downloader
   ```
- Install dependencies:
  ```bash
  pip install -r requirements.txt
  ```
- Update yt-dlp
  ``` bash
    pip install --upgrade yt-dlp
	```
- Run:
	``` bash
	python app.py
	```
